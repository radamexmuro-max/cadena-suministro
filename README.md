# Evolución de la Cadena de Suministro

**Alumno:** Radamés Muro - Logística U2
**Materia:** Logística y Cadena de Suministro

### Resumen
La cadena de valor de Porter se divide en actividades que generan valor al producto.

| Tipo de Actividad | Ejemplos | Función |
| :--- | :--- | :--- |
| **Soporte** | Finanzas, RRHH, Tecnología, Abastecimiento | Sostienen a toda la empresa |
| **Primarias** | Logística Inbound, Operaciones, Outbound, Marketing, Servicio | Crean y entregan el producto |

### Evolución en México

| Periodo | Característica | Quién manda |
| :--- | :--- | :--- |
| **1960-1990** | Comercio local, control de precios, poca variedad | Fabricante |
| **1990-2000** | TLC, globalización, nacen 3PLs e In-House | Retailer (Walmart) |
| **2000-2010** | China como fábrica del mundo, cliente exige todo rápido y perfecto | Cliente |

### Conceptos Clave
**Lead Time (APICS):** Tiempo total que tarda un proceso desde que inicia hasta que termina.

**Estrategias:**
- MTS (Make to Stock): Se fabrica para tener en stock
- ATO (Assembly to Order): Se ensambla cuando piden
- MTO (Make to Order): Se fabrica hasta que el cliente pide

**Caso éxito:** 7-Eleven - Cercanía, calidad y abierto 24 hrs.

### Conclusión
La logística pasó de ser solo bodega a ser la ventaja competitiva principal. Gana quien entrega más rápido y sin errores.
